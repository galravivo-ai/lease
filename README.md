## לפני עלייה – למפתח
1. **טופס לידים** (`#sc-lead-form`): כרגע מציג הודעת תודה בלבד ולא שולח לשום מקום. לחבר למערכת הלידים הקיימת (אותו endpoint של הטופס בעמודי הדגמים, או Elementor Form). שמות השדות: `full_name`, `phone`, `car`, `marketing_opt_in`.
2. **קטלוג:** הכרטיסים והמחירים כתובים ידנית לפי נתוני האתר מ-15.10.2026. אם רוצים שיתעדכנו לבד – להחליף את הגריד ב-Loop של JetEngine/Elementor ולשמור על המבנה וה-classes (`sc-car`, `data-price`, `data-types`) כדי שהסינון ימשיך לעבוד.
3. **ה-Schema:** אם Yoast כבר מוציא Organization/Breadcrumb – להשאיר רק את ה-OfferCatalog וה-FAQPage כדי לא לשכפל.
4. **תמונות:** נטענות מהשרת של Suncar (wp-content/uploads). ALT לכל רכב: "ליסינג פרטי [דגם] – Suncar".
5. **קישור חסר:** "מה עדיף – לקנות רכב או ליסינג" (בבלוק "על מה בא לך לקרוא?") מוביל ל-`#` – לא מצאתי מאמר כזה באתר. להחליף בכתובת המאמר או להסיר.
6. **גופן:** Heebo מ-Google Fonts. אם באתר כבר נטען Almoni/Heebo – אפשר למחוק את שורות ה-`<link>`.

## לאשר מול Suncar
- ה-Meta Description הנוכחי באוויר כתוב "ללא מקדמה", אבל כל הדגמים עם מקדמה ₪7,900.
- דירוג: בעמודי הדגמים 4.9 מ-1,240+ ביקורות, בשאר האתר 4.3 מ-508. בעמוד הזה – 4.3 / 508.
